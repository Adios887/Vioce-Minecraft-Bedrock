# My Voice Chat (โปรเจกต์เริ่มต้น)

โปรเจกต์นี้คือจุดเริ่มต้นของแอดออนวอยซ์แชทแบบ VCMC เป็นของตัวเอง
ประกอบด้วย 3 ส่วน ทำงานร่วมกัน:

```
vcmc-project/
├── addon/                     -> เอาไปแพ็กเป็น .mcaddon ลง Minecraft Bedrock
│   ├── behavior_pack/
│   │   ├── manifest.json
│   │   ├── pack_icon.png
│   │   └── scripts/main.js    -> อัปเดตสถานะไมค์ในเกม
│   └── resource_pack/
│       ├── manifest.json
│       ├── pack_icon.png
│       ├── font/glyph_E1.png  -> ไอคอนที่โผล่ต่อท้ายชื่อผู้เล่น
│       └── textures/ui/       -> ไฟล์ไอคอน 4 สถานะ (แยกไฟล์แล้ว)
│
├── backend/                    -> deploy ขึ้น Render.com (Web Service)
│   ├── server.js
│   └── package.json
│
└── frontend/                   -> เว็บไซต์ (เสิร์ฟจาก backend ให้อัตโนมัติ)
    ├── index.html
    ├── styles.css
    └── app.js
```

## หลักการทำงานโดยสรุป

1. ผู้เล่นติดตั้ง **behavior_pack + resource_pack** ลงในโลก/เซิร์ฟเวอร์
2. เปิด Cheats แล้วพิมพ์ในแชท:
   ```
   /connect ws://โดเมนของคุณที่ Render ให้มา/mc
   ```
   คำสั่งนี้คือฟีเจอร์มาตรฐานของ Minecraft Bedrock เอง (ไม่ใช่ของแอดออน)
   ที่เปิดช่องทาง WebSocket จากเกมไปหาเซิร์ฟเวอร์ภายนอก
3. `backend/server.js` จะสร้างรหัส 6 หลัก แล้วสั่งให้เกมพิมพ์รหัสนั้นในแชท
4. ผู้เล่นเปิดเว็บไซต์ (โดเมนเดียวกัน) กรอกรหัส + ชื่อผู้เล่น
5. เว็บไซต์กับเกมถูกจับคู่กันผ่านแบ็กเอนด์ จากนั้น:
   - สถานะไมค์ (ปิด/เปิด/พูดอยู่) จะถูกส่งกลับเข้าเกมเป็นไอคอนต่อท้ายชื่อ
   - เสียงจริงส่งกันแบบ P2P (WebRTC) ระหว่างเบราว์เซอร์ของผู้เล่นแต่ละคน
   - ถ้าเกมปิด/โลกถูกลบ/ถอด add-on → การเชื่อมต่อ `/connect` จะขาดเอง
     แบ็กเอนด์จะรู้ทันทีแล้วสั่งเว็บไซต์แสดง bubble แจ้งเตือน

## วิธี deploy (สรุปสั้น ๆ)

1. สร้าง repo บน GitHub แล้วอัปโหลดโฟลเดอร์นี้ทั้งหมด (ทำได้เลยจากที่นี่)
2. ไปที่ [render.com](https://render.com) → New → **Web Service**
3. เชื่อมกับ repo ที่เพิ่งสร้าง
4. ตั้งค่า:
   - **Root Directory**: `backend`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. หลัง deploy เสร็จ Render จะให้โดเมนมา เช่น `https://myvoicechat.onrender.com`
   - หน้าเว็บ = `https://myvoicechat.onrender.com`
   - คำสั่งในเกม = `/connect wss://myvoicechat.onrender.com/mc`
     (ใช้ `wss://` ไม่ใช่ `ws://` เพราะ Render ให้ HTTPS มาโดยอัตโนมัติ)

## การแพ็ก Add-On

1. บีบอัดโฟลเดอร์ `behavior_pack` และ `resource_pack` แยกกันเป็น `.zip`
   แล้วเปลี่ยนนามสกุลเป็น `.mcpack` (หรือรวมทั้งคู่เป็น `.mcaddon` ก็ได้)
2. เปิดไฟล์นั้นด้วย Minecraft (มือถือ/พีซี) เพื่อติดตั้งอัตโนมัติ
3. สร้างโลกใหม่ → เปิด Cheats → เพิ่ม behavior pack + resource pack ทั้งคู่

## สิ่งที่ยังเป็นแค่จุดเริ่มต้น (ต้องพัฒนาต่อ)

ระบบนี้ให้โครงที่ **รันได้จริง** และมีตรรกะหลักครบ (ยืนยันรหัส, สถานะไมค์,
ตรวจจับหลุดการเชื่อมต่อ, ส่งเสียงจริงผ่าน WebRTC, ปรับระยะ/ระดับเสียง)
แต่ยังมีจุดที่ควรพัฒนาต่อให้เนียนขึ้น:

- **ไอคอนสถานะบนหัวผู้เล่น** ใช้เทคนิค custom font glyph (ใน `font/glyph_E1.png`)
  ต่อท้ายชื่อผู้เล่น (`nameTag`) — ควรทดสอบในเกมจริงและปรับตำแหน่ง/ขนาดไอคอน
- **ไอคอนสถานะของตัวเอง** ตอนนี้ใช้ actionbar (รีเฟรชทุก tick ให้ดูค้างจอ)
  ซึ่งจะขึ้น "กลางล่างเหนือ hotbar" ไม่ใช่มุมซ้ายล่างเป๊ะ ๆ ตามที่ตั้งใจไว้
  ถ้าต้องการตำแหน่งอิสระจริง ต้องเขียน Custom JSON UI (ไฟล์ `ui/hud_screen.json`
  แบบ override) ซึ่งซับซ้อนกว่านี้มาก — ใช้เป็นเป้าหมายขั้นต่อไปได้
- **การคำนวณระยะเสียง (proximity)** ตอนนี้เทียบพิกัด x,y,z ตรง ๆ ยังไม่ได้
  เช็คว่าอยู่ dimension เดียวกันหรือเปล่า (Overworld/Nether/End)
- **เสียงตอนนี้เป็น P2P mesh** เหมาะกับกลุ่มเล็ก ๆ ไม่กี่คน ถ้าจะรองรับ
  ผู้เล่นพร้อมกันเยอะ ๆ ต้องทำ SFU (เช่นด้วยไลบรารี mediasoup) เพิ่มภายหลัง
- ฟิลด์ IP/พอร์ตในโหมด "เซิร์ฟเวอร์" ตอนนี้เก็บไว้แสดงผลเฉยๆ ยังไม่ได้ใช้
  งานจริงในแบ็กเอนด์ (การจับคู่ยังใช้รหัส 6 หลักเหมือนโหมดโลกส่วนตัวทุกอย่าง)

ไฟล์ทุกไฟล์มีคอมเมนต์ภาษาไทยอธิบายไว้ละเอียดแล้ว เอาไปให้ AI ตัวอื่นอ่านต่อได้เลย
